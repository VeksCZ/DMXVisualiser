# Vzorek projektu SoundSwitch (2502.ssproj)

`.ssproj` je ve skutečnosti složka. Z ní je zde jen to, co potřebuje import fixtures:

- `.ssproj` - JSON, verze SoundSwitch 2.11
- `SoundSwitchVenues.bin` - binární soubor s venues, fixtures, módy a kanály (formát zatím nedokumentován)

Vynecháno (desítky tisíc souborů, ~135 MB): `*.ssfile`, `*.ssa`, `SoundSwitchTrackMap.bin`, `SoundSwitchAutoLoops*.bin`.
